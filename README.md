# My E-commerce

![Projeye Genel Bakış](./assets/project-overview.png)

Bu proje **Next.js frontend** ve **Express + Mongoose backend** ile geliştirilmiş bir e-ticaret uygulamasıdır.  
Backend ürün verilerini MongoDB’de saklar, frontend ise bu verileri listeler ve yönetir.

---

## 🛠️ Gereksinimler

- **Node.js** (v20 veya üstü önerilir)  
- **npm** (Node.js ile birlikte gelir)  
- **MongoDB** (Lokal veya Atlas cloud)

> Node.js ve npm sürümünü kontrol etmek için:
```bash
node -v
npm -v
